MODULAR IRRIGATION NODE - WIRING LIST WITH EXPLANATIONS
Date: 2026-06-19

This wiring list matches the latest electronics direction:
- ESP32-S3 Zero as the controller.
- K548 USB-C LiPo charger.
- K585 boost converter adjusted to 5.0 V.
- K2402 donor kit for pump, capacitive soil sensor, hose, breadboard/wires.
- XSL-4510-P passive float switch for tank level.
- IRLB3034 or IRLZ44N logic-level N-MOSFET for pump switching.
- BH1750 light sensor and SHT30/SHT31 air temperature/humidity sensor.

Important safety notes:
- Set the K585 boost converter output to 5.0 V before connecting ESP32 or pump.
- Do not connect 5 V to any ESP32 GPIO.
- All grounds must be common.
- Pump current must not go through the ESP32 board pins.
- Observe diode and capacitor polarity.
- If using IRLB3034 instead of IRLZ44N, verify the physical pinout before soldering.


1. BATTERY TO CHARGER
=====================

1.1 Battery red wire -> K548 B+

Explanation:
This connects the positive side of the 3.7 V LiPo cell to the charger battery
positive terminal. The K548 charges the battery through this terminal.


1.2 Battery black wire -> K548 B-

Explanation:
This connects the negative side of the LiPo cell to the charger battery
negative terminal. This point becomes part of system ground.


2. CHARGER OUTPUT TO MAIN SWITCH
================================

2.1 K548 OUT+ -> main switch input pin

Explanation:
OUT+ is the positive system output from the charger module. It goes first to
the main power switch so the plant node can be turned off.


2.2 Main switch output pin -> switched battery positive rail

Explanation:
This is the positive supply rail after the switch. When the switch is on, this
rail carries the battery/charger output voltage to the rest of the circuit.


2.3 K548 OUT- -> common GND rail

Explanation:
OUT- is the charger load negative output. Connect it to the common ground rail.
Every module that shares signals with the ESP32 must share this same ground.


3. SWITCHED BATTERY RAIL TO BOOST CONVERTER
===========================================

3.1 Switched battery positive rail -> K585 IN+

Explanation:
The boost converter takes the LiPo voltage, roughly 3.0 V to 4.2 V, and raises
it to a stable 5 V rail for the ESP32 VIN/5V pin and the pump branch.


3.2 Common GND rail -> K585 IN-

Explanation:
This completes the input power path for the boost converter.


3.3 K585 OUT- -> common GND rail

Explanation:
The boost converter output ground must be tied to the same common ground as the
charger, ESP32, sensors, and MOSFET source. Without this, the ESP32 GPIO cannot
properly control the pump MOSFET.


4. 5 V BOOSTED RAIL
===================

4.1 K585 OUT+ -> +5V_BOOST rail

Explanation:
This is the regulated 5 V output. Adjust and measure it with a multimeter
before connecting anything sensitive.


4.2 +5V_BOOST rail -> ESP32-S3 Zero 5V/VIN pin

Explanation:
This powers the ESP32 board through its 5 V/VIN input. The board regulator then
creates 3.3 V for the ESP32 logic and low-power sensors.


4.3 Common GND rail -> ESP32-S3 Zero GND pin

Explanation:
The ESP32 must share ground with the charger, boost converter, sensors, MOSFET,
and pump protection parts. This is the reference for every GPIO signal.


5. ESP32 3.3 V SENSOR/LOGIC RAIL
================================

5.1 ESP32 3V3 pin -> +3V3_LOGIC rail

Explanation:
This rail powers the sensors and pull-up resistors that connect directly to
ESP32 GPIO/ADC pins. Keeping these at 3.3 V protects the ESP32 inputs.


5.2 +3V3_LOGIC rail -> BH1750 VCC

Explanation:
The BH1750 light sensor uses 3.3 V power so its I2C signals stay safe for the
ESP32.


5.3 +3V3_LOGIC rail -> SHT30/SHT31 VCC

Explanation:
The air temperature/humidity sensor is powered from the ESP32 3.3 V rail so its
I2C lines are also 3.3 V logic.


5.4 +3V3_LOGIC rail -> K2402 capacitive soil sensor VCC

Explanation:
The capacitive soil sensor can be powered from 3.3 V. This keeps its analog
output in the ESP32-safe voltage range.


6. SENSOR GROUNDS
=================

6.1 BH1750 GND -> common GND rail

Explanation:
The light sensor needs the same ground reference as the ESP32 I2C bus.


6.2 SHT30/SHT31 GND -> common GND rail

Explanation:
The air sensor needs the same ground reference as the ESP32 I2C bus.


6.3 K2402 capacitive soil sensor GND -> common GND rail

Explanation:
The soil sensor analog output is measured relative to ESP32 ground. If the
grounds are not common, the ADC reading will be wrong or unstable.


7. I2C SENSOR BUS
=================

7.1 ESP32 GPIO8 -> BH1750 SDA

Explanation:
GPIO8 is used as I2C data. It carries data between the ESP32 and BH1750.


7.2 ESP32 GPIO8 -> SHT30/SHT31 SDA

Explanation:
I2C is a shared bus, so both I2C sensors connect to the same SDA wire.


7.3 ESP32 GPIO9 -> BH1750 SCL

Explanation:
GPIO9 is used as I2C clock. The ESP32 controls timing on this line.


7.4 ESP32 GPIO9 -> SHT30/SHT31 SCL

Explanation:
Both I2C sensors share the same SCL clock wire.


Note:
Most BH1750/SHT30 breakout boards already include I2C pull-up resistors. If the
bus is unstable, add pull-ups from SDA to 3.3 V and SCL to 3.3 V, typically
4.7k to 10k. Do not pull I2C lines up to 5 V.


8. SOIL MOISTURE SENSOR SIGNAL
==============================

8.1 K2402 capacitive soil sensor AO -> ESP32 GPIO1_ADC1_CH0

Explanation:
AO is the analog moisture signal. The ESP32 reads it with an ADC pin and
firmware converts the raw ADC value into a calibrated soil moisture percentage.


8.2 Leave soil sensor DO unconnected, if present

Explanation:
Some soil modules have a digital comparator output. We do not need it because
the ESP32 should read the analog value and make its own calibrated decision.


9. BATTERY VOLTAGE MEASUREMENT
==============================

9.1 Switched battery positive rail -> 100k resistor R_BAT_H pin 1

Explanation:
This starts the battery voltage divider. It measures battery/system voltage
before the 5 V boost converter, which tells the firmware the real LiPo state.


9.2 R_BAT_H pin 2 -> BATTERY_ADC node

Explanation:
This is the midpoint of the voltage divider.


9.3 BATTERY_ADC node -> 100k resistor R_BAT_L pin 1

Explanation:
The lower resistor completes the divider and halves the battery voltage.


9.4 R_BAT_L pin 2 -> common GND rail

Explanation:
This connects the bottom of the divider to ground.


9.5 BATTERY_ADC node -> ESP32 GPIO2_ADC1_CH1

Explanation:
The ESP32 reads the divided battery voltage. With two 100k resistors:
- 4.2 V battery becomes about 2.1 V at the ADC.
- 3.7 V battery becomes about 1.85 V at the ADC.
- 3.3 V battery becomes about 1.65 V at the ADC.


10. TANK LEVEL SWITCH
=====================

10.1 ESP32 3V3 pin / +3V3_LOGIC rail -> 10k resistor R_LEVEL pin 1

Explanation:
This is the pull-up resistor for the tank level input. It makes the GPIO read
HIGH when the switch is open.


10.2 R_LEVEL pin 2 -> TANK_LEVEL node

Explanation:
This is the actual tank level signal node.


10.3 TANK_LEVEL node -> ESP32 GPIO6

Explanation:
The ESP32 reads this digital input to know whether the tank has water.


10.4 TANK_LEVEL node -> XSL-4510-P float switch lead 1

Explanation:
One side of the passive float switch connects to the GPIO signal node.


10.5 XSL-4510-P float switch lead 2 -> common GND rail

Explanation:
When the float switch closes, it pulls GPIO6 to GND, so the ESP32 reads LOW.
The XSL-4510-P is NC, so verify which physical position means wet/dry after
mounting. If the logic is backwards, invert it in firmware or flip the float if
the sensor construction allows it.


11. PUMP POWER PATH
===================

11.1 +5V_BOOST rail -> pump positive wire

Explanation:
The pump gets its power from the 5 V boost rail, not from an ESP32 pin.


11.2 Pump negative wire -> PUMP_LOW node

Explanation:
The pump negative side is not connected directly to ground. It goes to the
MOSFET drain so the ESP32 can switch the pump on and off.


11.3 PUMP_LOW node -> MOSFET drain

Explanation:
The MOSFET acts as a low-side switch. When the ESP32 drives the MOSFET gate
high, the MOSFET connects the pump negative side to ground and the pump runs.


11.4 MOSFET source -> common GND rail

Explanation:
This is the return path for pump current when the MOSFET is on.


12. MOSFET GATE CONTROL
=======================

12.1 ESP32 GPIO5 -> 100 ohm resistor R_GATE pin 1

Explanation:
GPIO5 is the pump control signal. The 100 ohm resistor limits fast gate-charge
current and helps reduce ringing/noise.


12.2 R_GATE pin 2 -> MOSFET gate

Explanation:
This delivers the ESP32 control signal to the MOSFET gate.


12.3 MOSFET gate -> 10k resistor R_PD pin 1

Explanation:
This is the MOSFET gate pulldown. It keeps the pump off while the ESP32 is
booting, reset, asleep, or disconnected.


12.4 R_PD pin 2 -> common GND rail

Explanation:
This gives the MOSFET gate a default LOW state.


13. PUMP FLYBACK DIODE
======================

13.1 1N5819 cathode/stripe side -> pump positive / +5V_BOOST side

Explanation:
The stripe side of the diode must face the positive pump supply.


13.2 1N5819 anode/non-stripe side -> pump negative / PUMP_LOW side

Explanation:
When the pump turns off, the motor creates a voltage spike. The diode gives
that spike a safe path and protects the MOSFET and ESP32 from electrical noise.


14. PUMP BULK CAPACITOR
=======================

14.1 470uF capacitor positive leg -> +5V_BOOST rail

Explanation:
The capacitor helps absorb pump startup current demand and reduces voltage dips.


14.2 470uF capacitor negative leg -> common GND rail

Explanation:
Electrolytic capacitors are polarized. The negative side must go to ground.


15. OPTIONAL NOISE CAPACITOR
============================

15.1 Optional 100nF ceramic capacitor -> across pump positive and pump negative

Explanation:
This can reduce high-frequency motor noise. It is optional for the prototype
and is not required in the current schematic.


16. CONNECTORS
==============

16.1 Pump connector pin 1 -> +5V_BOOST
16.2 Pump connector pin 2 -> PUMP_LOW

Explanation:
This connector lets the pump be disconnected from the electronics. Mark
polarity clearly.


16.3 Soil connector pin 1 -> 3.3 V
16.4 Soil connector pin 2 -> GND
16.5 Soil connector pin 3 -> GPIO1 ADC / SOIL_ADC

Explanation:
This makes the soil sensor replaceable. Use the actual pin labels on the soil
module; if its order is VCC-GND-AO, follow that order, not the connector order
above blindly.


16.6 Tank connector pin 1 -> GPIO6 / TANK_LEVEL
16.7 Tank connector pin 2 -> GND

Explanation:
This connects the XSL-4510-P float switch as a simple dry contact.


16.8 I2C connector pin 1 -> 3.3 V
16.9 I2C connector pin 2 -> GND
16.10 I2C connector pin 3 -> SDA / GPIO8
16.11 I2C connector pin 4 -> SCL / GPIO9

Explanation:
This 4-wire bus can connect BH1750 and SHT30/SHT31. If using separate modules,
both modules share the same four bus signals.


17. DO NOT CONNECT
==================

17.1 Do not connect K2402 relay module into the final pump design.

Explanation:
The final design uses a MOSFET because it is quieter, lower power, and better
for battery operation.


17.2 Do not connect K010 liquid-level controller into this node.

Explanation:
K010 needs 10-16 V. This plant node uses LiPo voltage and 5 V boost. Use
XSL-4510-P instead.


17.3 Do not power the pump from ESP32 3V3 or GPIO pins.

Explanation:
The pump current is far too high for GPIO pins and can reset or damage the
ESP32. The pump must be powered from the boost converter and switched by the
MOSFET.


18. QUICK BUILD ORDER
=====================

1. Wire battery to K548 charger.
2. Wire K548 OUT+ through the main switch.
3. Wire switched output to K585 IN+ and common GND to K585 IN-.
4. Adjust K585 output to exactly 5.0 V with a multimeter.
5. Connect K585 5 V output to ESP32 5V/VIN.
6. Connect ESP32 GND to common GND.
7. Build pump MOSFET circuit with diode and 470uF capacitor.
8. Test pump manually with firmware, short pulses only.
9. Add soil sensor to 3.3 V, GND, and GPIO1 ADC.
10. Add BH1750 and SHT30/SHT31 to I2C on GPIO8/GPIO9.
11. Add XSL-4510-P float switch to GPIO6 with 10k pull-up.
12. Add battery voltage divider to GPIO2 ADC.
13. Calibrate soil sensor, pump flow rate, and tank switch polarity.


19. ESP32 PIN SUMMARY
=====================

GPIO1_ADC1_CH0: soil moisture analog input
GPIO2_ADC1_CH1: battery voltage divider input
GPIO5: pump MOSFET gate control through 100 ohm resistor
GPIO6: tank level switch input with 10k pull-up
GPIO8: I2C SDA
GPIO9: I2C SCL
5V/VIN: powered from K585 5.0 V output
3V3: powers sensors and pull-up resistors
GND: common ground
