# Front/root node firmware

Това е бъдещият мост между mesh мрежата и HTTP/REST backend-а. Той ще регистрира plant nodes, ще буферира данни при липса на интернет и ще маршрутизира команди към правилния възел.

На този етап класовете са само договори. Няма Wi-Fi, ESP-NOW, друга mesh библиотека, HTTP клиент, буфер на диск или реално маршрутизиране.

Основно правило: front node може да поиска действие, но plant node взема окончателното решение след локалните проверки за безопасност.
